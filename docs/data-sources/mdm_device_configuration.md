# zentral_mdm_device_configuration (Data Source)

Finds a prepared per-device profile by exact full device serial and the stable name
of an app artifact it requires. This data source needs the Zentral fork's
`GET /api/mdm/devices/configuration_target/` endpoint. Older servers fail explicitly.
It never fetches profile source, a VPN key, an app package or a provisioning profile.

The server validates a unique active enrollment, native platform/OS/tag version
targeting, one exclusive device tag, and compatible attachment scope. Every version
with a nonempty rollout must remain exclusive to this device, including historical
versions and versions targeting other platforms. Broad scope, a shared tag or an
ambiguous configuration causes an error even when `allow_missing` is true.

Detached configurations and disabled attachments remain discoverable so they can
be assigned again. `attachment_id` identifies only the device's current blueprint
attachment and is null when detached. Configuration discovery requires an assigned
device blueprint.

`app_eligible` independently evaluates native app-version platform, OS and tag scope,
without requiring a blueprint assignment. It supports Store App, Enterprise App and
Configuration artifacts, including managed-app declarations. It does not prove signing
eligibility, provisioning validity, licensing, installation or connectivity. Set
`allow_missing = true` when checking an app that has no per-device profile.

This read-only lookup does not upload or activate a profile. Keep credential-bearing
source outside Terraform state. Serial numbers are stored in state; protect state
as personal data.

The API account requires `mdm.view_enrolleddevice`, `mdm.view_artifact`,
`mdm.view_blueprintartifact`, `inventory.view_machinesnapshot`, and `inventory.view_tag`.

## Example Usage

```terraform
data "zentral_mdm_device_configuration" "vpn" {
  serial_number = "EXAMPLE-SERIAL"
  app_name      = "WireGuard"
  allow_missing = true
}

output "prepared" {
  value = data.zentral_mdm_device_configuration.vpn.found
}
```

## Schema

### Required

- `app_name` (String) Exact stable name of the required app artifact.
- `serial_number` (String) Exact full device serial number.

### Optional

- `allow_missing` (Boolean) Defaults to false. Allow an absent enrollment, app or per-device configuration to return found=false. Unsafe scope and API failures remain errors. Set true when using app_eligible without a profile.

### Read-Only

- `app_eligible` (Boolean) Whether an app version's native platform, OS and tag scope includes the device, independent of blueprint assignment.
- `artifact_id` (String) Prepared profile artifact UUID, null when absent.
- `attachment_id` (Number) Attachment ID for the device's current blueprint, null when detached or absent.
- `found` (Boolean) Whether one exclusively scoped per-device configuration was found.
- `tag_id` (Number) Verified exclusive device tag ID, null when no configuration was found.
