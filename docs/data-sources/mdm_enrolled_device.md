# zentral_mdm_enrolled_device (Data Source)

Resolves the current enrollment ID by exact full serial number. Historical checked-out
and blocked enrollments are excluded. Ambiguous active matches cause an error. The
lookup reads all result pages and never sends device commands.

`allow_missing` stages devices that have not enrolled yet. Missing devices return
`found = false` and null computed identity fields. Permission failures, inconsistent
pagination and ambiguity remain errors. Re-enrollment produces a new ID, allowing
dependent resources to detect a changed enrollment identity.

Serial numbers and names are stored in state. Protect state as personal data.
The account requires `mdm.view_enrolleddevice`.

## Example Usage

```terraform
data "zentral_mdm_enrolled_device" "tablet" {
  serial_number = "EXAMPLE-SERIAL"
  allow_missing = true
}

output "enrolled" {
  value = data.zentral_mdm_enrolled_device.tablet.found
}
```

## Schema

### Required

- `serial_number` (String) Exact full device serial number.

### Optional

- `allow_missing` (Boolean) Allow a device that has not enrolled yet. Defaults to false. When true, a missing device returns found=false and null computed identity fields. API failures and ambiguous identities remain errors.

### Read-Only

- `blueprint_id` (Number) Current blueprint ID, or null when none is assigned.
- `found` (Boolean) Whether exactly one active, unblocked enrollment was found.
- `id` (Number) Zentral enrollment ID, or null when no eligible device was found.
- `name` (String) Cached inventory device name. Custom DeviceInformation commands do not refresh this value.
- `platform` (String) Device platform reported by Zentral.
- `supervised` (Boolean) Whether Zentral records the device as supervised.
