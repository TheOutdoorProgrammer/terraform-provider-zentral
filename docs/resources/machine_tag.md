# zentral_machine_tag (Resource)

Manages one direct inventory tag association for a machine that already has an inventory snapshot in Zentral. It preserves all unrelated tags. Refresh and planning only read membership; applying drift repair adds a missing association.

Use a separate resource for each machine/tag pair. Do not manage the same association in multiple resources or states. Import existing associations before managing them. Creating a resource for an existing association adopts it, and destroying the resource removes it regardless of who originally created it. Destroying the resource does not delete the tag or erase the device.

The API token needs `inventory.view_machinesnapshot`, `inventory.view_tag`, `inventory.add_tag`, `inventory.add_taxonomy`, `inventory.add_machinetag`, and `inventory.delete_machinetag` permissions. These reflect Zentral's permissions for the existing tag-update endpoint, even though this resource only associates existing tags.

Zentral's update API accepts tag names. The provider resolves the current name from the configured ID immediately before each mutation and checks the resulting membership. Avoid concurrent external tag renames or deletion during apply: the API does not provide atomic mutation by tag ID.

If a machine's inventory snapshots are removed, refresh removes this resource from state. The API cannot then report membership, even though the underlying tag association may still exist. Destroy while the machine remains in inventory when removing an association intentionally.

## Example Usage

```terraform
resource "zentral_tag" "device" {
  name = "example-ipad"
}

resource "zentral_machine_tag" "device" {
  serial_number = "EXAMPLE123"
  tag_id        = zentral_tag.device.id
}
```

## Schema

### Required

- `serial_number` (String) Exact inventory serial number of the machine. Requires replacement when changed. Stored in state.
- `tag_id` (Number) ID of an existing inventory tag. Requires replacement when changed.

### Read-Only

- `id` (String) Association identifier: unpadded base64url-encoded serial number, a slash, and the tag ID.

## Import

Import using the serial encoded as UTF-8, then unpadded base64url, followed by `/` and the tag ID:

```shell
# EXAMPLE123 encoded as unpadded base64url is RVhBTVBMRTEyMw.
terraform import zentral_machine_tag.device RVhBTVBMRTEyMw/42
```

The same import ID works with `tofu import`.
